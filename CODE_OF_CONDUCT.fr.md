# Code de conduite du projet

[English version](CODE_OF_CONDUCT.md)

Dendrila Privacy accueille les retours techniques, rapports de test et contributions de personnes ayant des niveaux d’expérience WordPress différents.

Les participants sont invités à :

- discuter des idées et du code sans attaques personnelles ;
- critiquer l’implémentation plutôt que la personne ;
- éviter les comportements discriminatoires, menaçants, harcelants ou volontairement humiliants ;
- respecter la vie privée : ne jamais publier les données personnelles, identifiants ou informations clients d’une autre personne ;
- garder les discussions suffisamment centrées pour que les mainteneurs et testeurs puissent agir.

Les mainteneurs peuvent modifier, masquer, fermer ou supprimer les contributions créant un problème de sécurité, de vie privée ou de harcèlement, ou empêchant de manière répétée une collaboration productive.

Les vulnérabilités doivent être signalées selon `SECURITY.fr.md` plutôt que d’exposer publiquement des détails sensibles.
