# Politique de sécurité

[English version](SECURITY.md)

## Signaler une vulnérabilité

Si vous découvrez une vulnérabilité pouvant exposer des données, contourner des permissions, compromettre un site WordPress ou affaiblir les protections de consentement de Dendrila Privacy :

1. ne publiez **pas** les détails d’exploitation dans une issue publique ;
2. utilisez le signalement privé de vulnérabilité / les Security Advisories GitHub lorsque cette fonction est activée sur le dépôt ;
3. indiquez la version de Dendrila Privacy concernée, les étapes de reproduction, l’impact attendu et les informations utiles sur l’environnement ;
4. retirez toute donnée personnelle, identifiant ou information client des captures et journaux.

Les bugs fonctionnels sans impact de sécurité peuvent utiliser le modèle public « Bug ».

## Versions prises en charge

Dendrila Privacy `0.0.5` est actuellement publiée sur WordPress.org. Les correctifs de sécurité ciblent la ligne de développement active puis sont intégrés à une version stable après validation.

Les versions de développement et builds intermédiaires ne doivent pas être considérées comme des versions de sécurité maintenues à long terme.
