# Politique de sécurité

[English version](SECURITY.md)

## Signaler une vulnérabilité

Si vous découvrez une vulnérabilité pouvant exposer des données, contourner des permissions, compromettre un site WordPress ou affaiblir les protections de consentement de PTM :

1. ne publiez **pas** les détails d’exploitation dans une issue publique ;
2. utilisez le signalement privé de vulnérabilité / les Security Advisories GitHub lorsque cette fonction est activée sur le dépôt ;
3. indiquez la version de PTM concernée, les étapes de reproduction, l’impact attendu et les informations utiles sur l’environnement ;
4. retirez toute donnée personnelle, identifiant ou information client des captures et journaux.

Les bugs fonctionnels sans impact de sécurité peuvent utiliser le modèle public « Bug ».

## Versions prises en charge

Dendrila Privacy est actuellement en préparation de la mise à jour WordPress.org (`0.0.5`). Les correctifs de sécurité ciblent la ligne de développement active puis sont reportés vers la branche de test stable après validation.

Aucune build de pré-publication ne doit être considérée comme une version de sécurité maintenue à long terme.
