# Security Policy

[Version française](SECURITY.fr.md)

## Reporting a vulnerability

If you discover a vulnerability that could expose data, bypass permissions, compromise a WordPress site, or weaken Dendrila Privacy's consent protections:

1. do **not** publish exploitation details in a public issue;
2. use GitHub Private Vulnerability Reporting / Security Advisories when enabled for the repository;
3. include the affected Dendrila Privacy version, reproduction steps, expected impact, and any relevant environment details;
4. remove personal data, credentials and client information from screenshots or logs.

Ordinary functional bugs with no security impact can use the public Bug issue template.

## Supported versions

Dendrila Privacy `0.0.5` is currently published on WordPress.org. Security fixes target the active development line and are included in a stable release after validation.

Development versions and intermediate builds should not be treated as long-term supported security releases.
